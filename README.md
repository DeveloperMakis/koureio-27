# ΤΟ ΚΟΥΡΕΙΟΝ 27 — Website & Online Ραντεβού

Επαγγελματικό website με σύστημα online κρατήσεων για το barbershop **ΤΟ ΚΟΥΡΕΙΟΝ 27** (Χειμάρρας 22, Κορυδαλλός).

Stack: **Next.js 14 (App Router) · TypeScript · Tailwind CSS · Prisma · SQLite (dev) / PostgreSQL (prod) · iron-session**.

---

## 1. Γρήγορη εκκίνηση (τοπικά)

```bash
# 1. Εγκατάσταση
npm install

# 2. Μεταβλητές περιβάλλοντος
cp .env.example .env
#   - Βάλτε DATABASE_URL (η προεπιλογή SQLite δουλεύει αμέσως)
#   - Δημιουργήστε SESSION_SECRET (32+ χαρακτήρες): openssl rand -base64 32

# 3. Βάση δεδομένων (δημιουργία πίνακων + αρχικά δεδομένα)
npm run db:push
npm run db:seed

# 4. Πρώτος διαχειριστής (βλ. §3)
npm run create-admin -- admin@koureion27.gr "ΈναςΙσχυρόςΚωδικός"

# 5. Εκκίνηση
npm run dev            # http://localhost:3000
# ή για production build:
npm run build && npm run start
```

## 2. Πού ρυθμίζονται τα πάντα

Τα δεδομένα είναι **καθαρά διαχωρισμένα**:

| Τι | Πού |
|---|---|
| Στοιχεία επιχείρησης (διεύθυνση, τηλέφωνα, ωράριο, social, χάρτης, αργίες) | `src/config/business.ts` |
| Κατάλογος υπηρεσιών (αρχικό seed) | `src/config/services.ts` |
| Ρυθμίσεις κρατήσεων (βήμα slot, lead time, όριο ημερών, ακύρωση) | `src/config/booking.ts` |
| Κείμενα σελίδων (hero, «ο χώρος μας», FAQ, gallery) | `src/content/site.ts` |
| Σύνδεση εξωτερικών υπηρεσιών | `.env` |

**Υπηρεσίες, τιμές, διάρκειες, κλεισίματα και ραντεβού** διαχειρίζονται ζωντανά από το **/admin** (αποθηκεύονται στη βάση).

> Τα επαληθευμένα στοιχεία (διεύθυνση, τηλέφωνα, ωράριο) είναι ήδη συμπληρωμένα στο `business.ts` από Google Maps + το επίσημο Instagram. **Ελέγξτε τα πριν τη δημοσίευση.**

## 3. Διαχειριστικό (/admin)

- Σύνδεση: `/admin/login` (προστατεύεται με iron-session + bcrypt).
- **Ημερολόγιο** ημέρας/εβδομάδας με όλα τα ραντεβού.
- **Νέο ραντεβού** (τηλεφωνικό/επιτόπιο) από τον διαχειριστή.
- Ενέργειες ανά ραντεβού: **Ολοκληρώθηκε / Μη προσέλευση / Ακύρωση**.
- **Υπηρεσίες**: ενεργοποίηση/απενεργοποίηση, τιμή, διάρκεια, σειρά.
- **Κλεισίματα**: κλείσιμο ωρών ή ολόκληρων ημερών / αδειών.

### Δημιουργία πρώτου διαχειριστή
```bash
npm run create-admin -- <email> <password>
# ή: ADMIN_EMAIL=... ADMIN_PASSWORD=... npm run create-admin
```

> **Οι δημόσιες online κρατήσεις είναι ΚΛΕΙΣΤΕΣ μέχρι ο ιδιοκτήτης να ενεργοποιήσει
> τουλάχιστον μία υπηρεσία** από το `/admin/services`. Μέχρι τότε η σελίδα ραντεβού
> εμφανίζει τις επιλογές τηλεφωνικής επικοινωνίας (σχεδιαστική επιλογή, όχι σφάλμα).

## 4. Σύστημα κρατήσεων — πώς δουλεύει

- Ροή: υπηρεσία → (κουρέας, αν >1) → ημέρα & ώρα → στοιχεία → επιβεβαίωση.
- Χωρίς υποχρεωτικό λογαριασμό. Πληρωμή στο κατάστημα.
- Διαθεσιμότητα υπολογισμένη από ωράριο κουρέα + διάρκεια υπηρεσίας + υπάρχουσες
  κρατήσεις + κλεισίματα, σε ζώνη ώρας **Europe/Athens** (με σωστό χειρισμό DST).
- **Αποτροπή διπλοκράτησης σε δύο επίπεδα**: έλεγχος επικάλυψης μέσα σε transaction
  **και** μοναδικό `slotKey` στη βάση — ανθεκτικό ακόμη και σε ταυτόχρονες αιτήσεις.
- Μοναδικός κωδικός κράτησης + ασφαλής σύνδεσμος διαχείρισης/ακύρωσης.
- **Προσθήκη στο ημερολόγιο** μέσω αρχείου `.ics`.
- Προστασία φορμών: server-side validation (zod), rate limiting, honeypot.

## 5. Παραγωγή με PostgreSQL

1. Στο `prisma/schema.prisma` αλλάξτε `provider = "postgresql"`.
2. Βάλτε το `DATABASE_URL` του Postgres στο `.env`.
3. `npm run db:push` (ή migrations) και `npm run db:seed`.

Το σχήμα είναι συμβατό και με τα δύο. Σε Postgres με πολλαπλές διεργασίες, για
απόλυτη εγγύηση σε ακραία ταυτόχρονη κίνηση, μπορεί να προστεθεί advisory lock /
serializable transaction (ο υπάρχων μηχανισμός `slotKey` ήδη αποτρέπει διπλοκράτηση).

## 6. Email / SMS (προαιρετικό — ΔΕΝ είναι συνδεδεμένο)

Οι επιβεβαιώσεις/υπενθυμίσεις στέλνονται **μόνο όταν συνδεθεί πραγματικός πάροχος**
μέσω των μεταβλητών στο `.env.example`. Μέχρι τότε το σύστημα **δεν προσποιείται**
ότι έστειλε μήνυμα. Τα σημεία σύνδεσης (hooks) προβλέπονται· χρειάζεται υλοποίηση
του αποστολέα και τα κλειδιά του παρόχου.

## 8. Προσθήκη πραγματικών φωτογραφιών

## 10. Αποτελέσματα ελέγχων που εκτελέστηκαν

- ✅ `npm run build` — επιτυχής (type-check καθαρό, 20 routes).
- ✅ Responsive: δοκιμή σε mobile (375px) & desktop — χωρίς οριζόντιο scroll, sticky header,
  κάτω μπάρα κινητού (Ραντεβού/Κλήση/Οδηγίες).
- ✅ Πλήρης ροή κράτησης (υπηρεσία → ώρα → στοιχεία → επιβεβαίωση + κωδικός + .ics).
- ✅ **Ταυτόχρονη κράτηση ίδιας ώρας** → 1η επιτυχία (200), 2η απόρριψη (409 SLOT_TAKEN).
- ✅ Έλεγχος επικάλυψης: διπλανές ώρες σωστά αποκλείονται (11:00 κλειστό → 11:15 κλειστό, 11:30 ανοιχτό).
- ✅ Ακύρωση → απελευθέρωση διαθεσιμότητας → επανακράτηση ίδιας ώρας.
- ✅ Κλειστές ημέρες (Δευτέρα/Κυριακή) → καμία διαθέσιμη ώρα.
- ✅ Ζώνη ώρας/DST: 12:00 Αθήνα (Οκτ, EEST) → 09:00Z αποθήκευση — σωστό.
- ✅ Προστασία `/admin`: μη εξουσιοδοτημένος χρήστης → redirect στο login.
- ✅ Admin: σύνδεση, ενεργοποίηση υπηρεσίας, ημερολόγιο, ενέργειες ραντεβού.

> Μετά τους ελέγχους, η βάση επαναφέρθηκε σε **καθαρή κατάσταση** (υπηρεσίες ανενεργές,
> χωρίς τιμές, χωρίς δοκιμαστικά ραντεβού, χωρίς δοκιμαστικό διαχειριστή).
